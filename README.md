# CivilGPT

Плагин для Autodesk Civil 3D 2022, автоматизирующий работу инженера-геодезиста и проектировщика.

Загружается в процесс Civil 3D через `NETLOAD`. Внутри — команды AutoCAD/Civil 3D
и ИИ-помощник (function calling), который вызывает те же операции по текстовому запросу.

## Целевая платформа

| Параметр | Значение | Почему |
|---|---|---|
| Civil 3D | 2022 (R24.1) | установленная версия на рабочей машине |
| .NET | Framework 4.8 | Civil 3D 2022 загружает только .NET Framework 4.8 |
| Платформа | x64 | AutoCAD не существует в 32-битной версии |
| Тип сборки | Library (DLL) | плагин, а не отдельное приложение |

## Сборка

```powershell
.\build.ps1                 # Release
.\build.ps1 -Configuration Debug
```

Скрипт чистит `bin`/`obj`, предупреждает, если запущен Civil 3D, и собирает плагин.

Эквивалентная команда вручную:

```powershell
dotnet build CivilGPT.csproj -c Release -p:Platform=x64
```

**Важно:** если Civil 3D запущен, он держит `CivilGPT.dll` и сборка не сможет переписать файл.
Перед сборкой закройте Civil 3D.

Результат: `bin\x64\Release\CivilGPT.dll` и `appsettings.json` рядом с ним.

## Загрузка в Civil 3D

1. Запустить Civil 3D 2022.
2. Команда `NETLOAD` → выбрать `CivilGPT.dll`.
3. В командной строке появятся сообщения о загрузке и списке команд.

Чтобы плагин загружался автоматически, добавьте сборку в реестр
`HKCU\Software\Autodesk\AutoCAD\R24.1\ACAD-5100:419\Applications\CivilGPT`
(ключ `LOADCTRLS = 2`, `LOADER = <путь к CivilGPT.dll>`).

## Команды

Работа с рельефом разделена на два шага: подготовка горизонталей и сборка поверхности.

| Команда | Назначение |
|---|---|
| `CGTINCONTOURS` | подготовить горизонтали: найти линии и подписи на слое, восстановить высоты, создать копии полилиний с отметками |
| `CGTINSURFACE` | собрать TIN: создать или дополнить поверхность, добавить характерные линии (брейклайны) и внешнюю границу |
| `CIVILGPT` | открыть панель ИИ-помощника |
| `RANDOMIZEPOINTZ` | случайное отклонение отметок выделенных точек COGO от проектных |
| `RANDOMIZEPOINTXY` | случайное плановое отклонение всех точек COGO в осях текущей ПСК |
| `CREATEDOFFSETPOINTS` | создать точки со случайным смещением в новой группе точек |

### CGTINCONTOURS — подготовка горизонталей

1. Укажите любую горизонталь — по ней определяется слой, остальные объекты берутся с этого слоя.
2. Задайте допуск привязки подписи к линии (по умолчанию 1 м).
3. Команда соберёт кривые и подписи, свяжет каждую подпись с ближайшей линией и создаст
   копии линий в виде полилиний на слое `CIVILGPT_TIN` с высотой по подписи.

Исходные объекты не изменяются — создаются копии.

Подписи распознаются в двух видах:

| Вид | Пример | Трактовка |
|---|---|---|
| Полная отметка | `205.00`, `204,8`, `205` | абсолютная высота, служит опорой |
| Сокращённая | `70`, `05`, `7` | две последние цифры; разворачивается от ближайшей полной |
| Не отметка | `д.к.`, `о.к.`, `ПК 12+50`, `Ворота` | отбрасывается |

Сокращённые отметки разворачиваются по ближайшей полной: подпись `70` при опоре `205.00`
даёт `204.70`, а не `205.70` — выбирается значение, ближайшее к опорному.

### CGTINSURFACE — сборка поверхности

1. Выберите существующую TIN-поверхность или нажмите Enter, чтобы создать новую
   (тогда понадобится имя; горизонтали берутся со слоя `CIVILGPT_TIN`).
2. Выберите характерные линии — бровки, лотки, уступы (Enter — пропустить).
   Они добавляются как стандартные брейклайны.
3. Выберите замкнутую границу участка (Enter — без границы).
   Добавляется как внешняя граница с отсечением.

В отчёте выводятся количество горизонталей, брейклайнов, наличие границы,
число вершин и диапазон отметок поверхности.

## Настройка ИИ

Ключ API в репозитории не хранится. Задайте его одним из способов:

```powershell
# переменная окружения (приоритетнее appsettings.json)
setx CIVILGPT_Ai__DeepSeek__ApiKey "sk-..."
# или резервный вариант
setx DEEPSEEK_API_KEY "sk-..."
```

Провайдер переключается в `appsettings.json` через `Ai:DeepSeek:BaseUrl` и `Ai:DeepSeek:Model`.
Клиент совместим с OpenAI API, поэтому подходят DeepSeek, OpenRouter, OpenAI, локальная Ollama.

Без ключа плагин полностью работоспособен: команды AutoCAD доступны, ИИ-слой
подменяется заглушкой `StubLlmClient`.

## Структура

```
AI/                     ИИ-слой
  AiOrchestrator.cs     запрос → инструмент → ответ
  ToolRegistry.cs       реестр инструментов (reflection)
  ILlmClient.cs         контракт провайдера + DTO
  DeepSeekLlmClient.cs  OpenAI-совместимый клиент с function calling
  Tools/                инструменты, доступные ИИ
CAD/                    слой интеграции с AutoCAD / Civil 3D
  Common/               документ, база, редактор, выделение, транзакции, маршалинг
  Blocks/               анализ и трансформация блоков, динамические блоки
  Geometry/             ПСК/МСК, матрицы, габариты, расширения точек
  Cogo/                 сервисы точек COGO
  Contours/             разбор подписей, восстановление высот, подъём горизонталей
  Surfaces/             определения поверхности: горизонтали, брейклайны, границы
Commands/               команды AutoCAD (CommandMethod)
Configuration/          загрузка настроек
Infrastructure/         JsonHelper — собственная реализация JSON
Models/                 параметры операций
UI/                     панель WPF (PaletteSet)
```

## Замечания по реализации

- **Никаких сторонних зависимостей.** Плагин ссылается только на сборки .NET Framework
  и AutoCAD. Это принципиально: в процессе AutoCAD нельзя применить binding redirect,
  поэтому любая NuGet-зависимость (System.Text.Json, System.Memory и их транзитивные
  зависимости) рискует не загрузиться из-за конфликта версий. JSON реализован
  самостоятельно в `Infrastructure/JsonHelper.cs`.
- **Кодировка исходников.** Файлы в UTF-8 без BOM, поэтому в проекте задан
  `<CodePage>65001</CodePage>`. Без него компилятор читает исходники в системной
  ANSI-кодировке и кириллица в строках превращается в кракозябры.
- **Маршалинг потоков.** API Civil 3D не потокобезопасен. Вызовы из панели ИИ
  проходят через `CadDispatcher.ExecuteInApplicationContext`, который дожидается
  выполнения, а `AiOrchestrator` использует `ConfigureAwait(false)`, чтобы продолжение
  не выполнялось на потоке UI AutoCAD и не приводило к взаимной блокировке.
- **Блокировка документа.** Операции записи, инициированные из немодальной панели,
  выполняются под `Document.LockDocument()`.
- **ПСК/МСК.** Отклонения «по осям чертежа» считаются в текущей ПСК инженера
  и затем переводятся в МСК — иначе на повёрнутом виде смещения уходят не туда.
- **Заблокированные точки COGO** пропускаются, их количество выводится в отчёт.

## Ограничения текущей версии

- Сечение рельефа не запрашивается: сокращённые отметки разворачиваются по ближайшей
  полной без проверки постоянства шага. Для чертежей с частыми полными отметками
  это работает, для разреженных — требует проверки.
- Горизонталь без подписи не получает высоту и в поверхность не попадает
  (счётчик выводится в отчёте).
- Подпись, стоящая далеко от своей линии (не в разрыве), не привяжется —
  регулируется допуском.
- Отрисовка комплектов КЖ по DWG — отложено по решению заказчика.
- Многошаговые сценарии ИИ (сейчас один вызов инструмента за запрос).
